During the pre-drill rehearsal, the backupadmin account
failed to authenticate against the DR portal. The account
was provisioned on 2026-03-30 but the password was set
incorrectly during automation.

[IT Ops - Day 1, 09:30]
Root cause: The provisioning script used "PhoenixDR" (no
underscore) instead of "Phoenix_DR". The project identifier
in the password must match the project charter exactly.

Correct format for IT Admin / Operations accounts:
  <ProjectName>#<Year>
  Where ProjectName = "Phoenix_DR" (with underscore)

Password corrected. Rehearsal completed successfully.
